# Curso Completo de Desenvolvimento Web

Este repositório contém materiais e projetos do Curso Completo de Desenvolvimento Web, focado em JavaScript e suas principais tecnologias.

## Estrutura do Curso

O curso está dividido em 12 seções, cobrindo desde os fundamentos de JavaScript até o desenvolvimento de aplicações completas com React Native.

## Projetos Principais

Durante o curso, são desenvolvidos três projetos principais interconectados:

1. **Backend Pizzaria (Node.js)** - Sistema completo de gerenciamento para pizzaria
2. **Frontend Web Pizzaria (Next.js)** - Interface administrativa para gerenciar pedidos e produtos
3. **App Mobile Pizzaria (React Native)** - Aplicativo para clientes e entregadores

## Pré-requisitos

- Conhecimentos básicos de HTML e CSS
- Computador com Node.js instalado
- Editor de código (recomendado: VS Code)
- Entusiasmo para aprender!

## Como Utilizar Este Repositório

1. Clone o repositório para sua máquina local
2. Navegue pelas pastas de cada seção para acessar os códigos e materiais
3. Acompanhe as aulas e pratique os exercícios propostos
4. Desenvolva os projetos junto com o curso

## Tecnologias Abordadas

- JavaScript

- Bancos de dados (utilizados no projeto Pizzaria)
- Autenticação e autorização
- Deployment e publicação
